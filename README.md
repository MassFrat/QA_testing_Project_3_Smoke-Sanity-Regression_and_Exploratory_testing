### What Is This Project?

This project tests the **nopCommerce demo e-commerce store** using four different types of manual testing. It is part of my QA portfolio to demonstrate real-world testing skills for job applications.

**Application tested:** https://demo.nopcommerce.com

---

### Test Types Covered

| Test Type | What It Means | How Many Tests |
|---|---|:---:|
| **Smoke** | Quick check — is the app working at all? | 10 |
| **Sanity** | Did a specific bug fix actually work? | 8 |
| **Regression** | Did a code change accidentally break something? | 35 |
| **Exploratory** | Creative unscripted testing to find unexpected bugs | 1 session (25 mins) |
| **Total** | | **53** |
